# HydroWise brand assets

These assets follow the HydroWise Brand Asset Guide. The symbol geometry is traced from the supplied official HydroWise artwork into standalone SVG paths; no raster image is embedded.

| Asset | Intended use |
|---|---|
| `hydrowise-horizontal.svg` | Standard horizontal web/desktop lockup |
| `hydrowise-horizontal-light.svg` | Horizontal lockup on dark navy surfaces |
| `hydrowise-stacked.svg` | Large-format or centered brand presentation |
| `hydrowise-monochrome.svg` | High-contrast print and single-color contexts |
| `hydrowise-mark-gradient.svg` | Primary traced symbol-only mark |
| `hydrowise-mark-light.svg` | Symbol-only mark on dark surfaces |
| `hydrowise-mark-leaf.svg` | Environmental alternate-color symbol |
| `hydrowise-mark-monochrome.svg` | Single-color symbol |
| `hydrowise-app-icon.svg` | App tile and platform icon |
| `hydrowise-favicon.svg` | Browser favicon |

The dashboard uses `hydrowise-horizontal-light.svg` in the desktop sidebar and `hydrowise-mark-light.svg` in compact navigation. The favicon and touch icon are wired through `apps/web/index.html`.
