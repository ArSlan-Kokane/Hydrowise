# HydroWise brand assets

These assets follow the HydroWise Brand Asset Guide and are standalone SVG files. They contain vector paths and SVG text only; no supplied raster image is embedded.

| Asset | Intended use |
|---|---|
| `hydrowise-horizontal.svg` | Standard horizontal web/desktop lockup |
| `hydrowise-horizontal-light.svg` | Horizontal lockup on dark navy surfaces |
| `hydrowise-stacked.svg` | Large-format or centered brand presentation |
| `hydrowise-monochrome.svg` | High-contrast print, accessibility, and single-color contexts |
| `hydrowise-mark-gradient.svg` | Primary symbol-only mark |
| `hydrowise-mark-light.svg` | Symbol-only mark on dark surfaces |
| `hydrowise-mark-leaf.svg` | Environmental/alternate color symbol |
| `hydrowise-mark-monochrome.svg` | Single-color symbol |
| `hydrowise-app-icon.svg` | App tile and platform icon |
| `hydrowise-favicon.svg` | Browser favicon |

The dashboard uses `hydrowise-horizontal-light.svg` in the desktop sidebar and `hydrowise-mark-light.svg` in the compact navigation state. The favicon and touch icon are wired through `apps/web/index.html`.
